# Design decisions

Ask the owner explicitly before making new design decisions, including adding
visible text, helper copy, headings, badges, dialogs, or other UI clutter. Do not
treat empty space as something to fill. An explicit user instruction authorizes
that specific change; ask about additional design choices.

Follow `docs/SPEC.md` for the web app. Prefer concise control labels
and whitespace. Keep explanations behind requested info controls or Help/Credits;
do not add promotional copy, reassurance, or redundant status text to app screens.
